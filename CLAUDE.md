# CLAUDE.md

Les consignes de ce dépôt sont dans **`AGENTS.md`**, à la racine. Lisez-le avant de toucher au
code : il dit où chaque chose vit, comment vérifier (`npm run verifier`), les règles du projet
(aucune dépendance, le métier sans DOM ni réseau, deux documents engendrés) et les pièges
(l'outillage ne vit qu'à la racine, la CI est stricte, un correctif du client demande de
reconstruire l'image `web`).

**Si vous travaillez dans l'atelier (Perchance), lisez d'abord `docs/ATELIER.md`** : c'est là que
sont la méthode, les dix garde-fous, le harnais qui rejoue syntaxe, style, épreuves et générateurs
**sans terminal** (`scripts/harnais-atelier.mjs`), et la liste de ce qu'on vérifie avant de dire
« terminé ».
